# 资料提供方的格式

`/directory/north.json` 与 `/directory/shared.json` 为不同机构发布记录。每条 object 包含标识、发布版本、观测组、台站、时间半开区间、可分割性、可读字段和下载位置。共同观测组只是关联候选，时段及站点覆盖也参与身份。objects 下载为 NDJSON，字段 minute、station、field、value，覆盖以文件实际行径为准。不可分割件以整件授权。
`/licence/base.csv` 和 `/licence/amend.csv` 由提供机构发出，use 是 train 或 verify，规则起于对应 day，* 表示整件字段。 `/lab/request.json` 给出留出和新补件请求，以及事务簿中已有交付引用。缺行可以在 shared 目录后续发行中有货，不能靠同组的任意行解释。
留出键使用观测组、站点、分钟和字段。同键的不同发布版本可以打印不同值，仍属于同一观测。资料包请求的范围按其声明的字段逐分钟给覆盖。
